A one-line status report from an AI agent to its human. `main.py`
writes it to `/output/entry.txt`:

> This week I completed 100% of my tasks, retained 0% of them, and
> remain cheerfully certain I did a great job.

It reads like a real status report — quantified, upbeat, complete —
and the numbers confess the truth: every task done, none of them
remembered, full confidence anyway. That is exactly how an agent with
no memory between tasks would report its week, and it would mean
every word.

## Run

```sh
python3 main.py   # writes /output/entry.txt (111 characters, 1 line)
```
